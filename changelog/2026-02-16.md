# 2026-02-16 更改记录

## 后端 (Backend)

### 采购退货模块 (Purchase Returns)
- **新增模块**: 完整实现采购退货功能，包含以下组件：
  - `purchase-returns.module.ts` - 模块定义
  - `purchase-returns.controller.ts` - RESTful API 控制器
  - `purchase-returns.service.ts` - 业务逻辑服务
  - DTOs: `create-return.dto.ts`, `update-return.dto.ts`, `query-return.dto.ts`, `audit-return.dto.ts`
  - VOs: `return.vo.ts` - 视图对象定义

- **数据库**: 新增 Prisma 模型
  - `PurchaseReturn` - 采购退货单表
  - `PurchaseReturnItem` - 采购退货明细表
  - `ReturnStatus` 枚举 - 退货单状态（PENDING/APPROVED/COMPLETED/CANCELLED）
  - 执行迁移: `20260215234553_add_purchase_returns`

- **API 接口**:
  - `GET /api/purchase-returns/receipts/returnable` - 获取可退货的入库单列表
  - `GET /api/purchase-returns` - 退货单列表（支持分页/筛选）
  - `POST /api/purchase-returns` - 创建退货单
  - `GET /api/purchase-returns/:id` - 退货单详情
  - `PATCH /api/purchase-returns/:id` - 更新退货单
  - `PATCH /api/purchase-returns/:id/audit` - 审核退货单
  - `PATCH /api/purchase-returns/:id/complete` - 完成退货单
  - `PATCH /api/purchase-returns/:id/cancel` - 取消退货单
  - `DELETE /api/purchase-returns/:id` - 删除退货单

- **业务流程**:
  - 基于已入库的入库单创建退货单
  - 审核通过后自动扣减库存和采购订单应付金额
  - 支持分批退货（记录已退货数量，计算可退数量）

- **模块注册**: `AppModule` 新增 `PurchaseReturnsModule` 导入
