# 2026-02-16 更改记录

## 概述
本次提交包含 V1.0 版本多个核心功能模块的实现：商品管理（SPU/SKU）、库存管理、商城前台、进销存采购管理、文件存储等。同时包含前端架构优化（VO 层重构、类型定义规范化、状态管理目录调整）。

---

## 后端 (Backend)

### 🏗️ 架构规范
- **VO 层重构**: 为所有核心模块新增统一的 Value Object 层
  - 所有列表/详情查询接口返回 VO 对象，解耦数据库实体与 API 响应
  - 统一字段命名规范（如 `supplierName` 替代 `supplier.name`）

### 📦 商品管理模块 (Products)
- **新增模块**:
  - `products.module.ts` - SPU/SKU 管理
  - `products.controller.ts` - RESTful API（CRUD、状态切换、SKU 管理）
  - `products.service.ts` - 业务逻辑（含规格模板解析、SKU 自动生成）
  - DTOs: `create-product.dto.ts`, `update-product.dto.ts`, `query-product.dto.ts`, `update-sku.dto.ts`
  - VOs: `product.vo.ts`, `product-sku.vo.ts`

- **数据库表**: `Product`, `ProductSku`
  - 支持规格模板（JSON）、多 SKU、图片管理
  - 商品状态：草稿/待审核/已通过/已拒绝/已禁用
  - SKU 状态：启用/禁用/已删除

### 📦 库存管理模块 (Inventories)
- **新增模块**:
  - `inventories.module.ts` - 多仓库库存管理
  - `inventories.controller.ts` - API（查询、更新、初始化、预警）
  - `inventories.service.ts` - 库存计算逻辑（实际/可用/锁定库存）
  - DTOs: `query-inventory.dto.ts`, `update-inventory.dto.ts`
  - VOs: `inventory.vo.ts`

- **数据库表**: `Inventory`
  - 字段: quantity（实际）, locked（锁定）, available（可用）, minStock/maxStock（预警）
  - 唯一约束: [skuId, warehouseId]

### 🛒 商城前台模块 (Mall)
- **新增模块**:
  - `mall.module.ts` - 商城前台接口（无需登录）
  - `mall.controller.ts` - API（商品列表、商品详情、分类/品牌列表）
  - `mall.service.ts` - 商城业务逻辑（过滤已禁用商品）
  - DTO: `query-mall-product.dto.ts`

### 📦 进销存 - 采购管理
#### 采购订单 (Purchases)
- **新增模块**:
  - `purchases.module.ts`, `purchases.controller.ts`, `purchases.service.ts`
  - DTOs: `create-purchase.dto.ts`, `update-purchase.dto.ts`, `query-purchase.dto.ts`, `audit-purchase.dto.ts`
  - VO: `purchase.vo.ts`

- **数据库表**: `Purchase`, `PurchaseItem`
- **状态流转**: PENDING → APPROVED → PARTIAL → COMPLETED / CANCELLED

#### 采购入库 (Purchase Receipts)
- **新增模块**:
  - `purchase-receipts.module.ts`, `purchase-receipts.controller.ts`, `purchase-receipts.service.ts`
  - DTOs: `create-receipt.dto.ts`, `query-receipt.dto.ts`
  - VO: `receipt.vo.ts`

- **数据库表**: `PurchaseReceipt`, `PurchaseReceiptItem`
- **特性**: 分批入库、库存自动增加、加权平均成本计算

#### 采购退货 (Purchase Returns)
- **新增模块**:
  - `purchase-returns.module.ts`, `purchase-returns.controller.ts`, `purchase-returns.service.ts`
  - DTOs: `create-return.dto.ts`, `update-return.dto.ts`, `query-return.dto.ts`, `audit-return.dto.ts`
  - VO: `return.vo.ts`

- **数据库表**: `PurchaseReturn`, `PurchaseReturnItem`
- **特性**: 基于入库单退货、可退数量计算、审核后扣减库存和应付金额

### 💰 财务管理 - 收付款 (Payments)
- **新增模块**:
  - `payments.module.ts`, `payments.controller.ts`, `payments.service.ts`
  - DTOs: `create-payment.dto.ts`, `query-payment.dto.ts`
  - VO: `payment.vo.ts`

- **数据库表**: `Payment`
- **功能**: 采购付款登记、应付款统计、付款核销

### 📁 文件存储 (MinIO)
- **新增模块**:
  - `minio.module.ts` - 基于 MinIO 的对象存储
  - `minio.controller.ts` - 文件上传/删除/预签名 URL API
  - `minio.service.ts` - MinIO 客户端操作
  - DTOs: `file.dto.ts`, `response.dto.ts`

- **功能**: 单文件/多文件上传、图片预览、文件删除
