## 前端

### 新增：主题模式切换 + 主题颜色系统

支持三种主题模式：
- **light**: 强制亮色模式
- **dark**: 强制暗色模式  
- **auto**: 跟随操作系统主题

同时支持灰度模式、色弱模式辅助功能，以及完整的主题颜色系统。

#### 核心实现

**三层颜色控制架构：**
```
CSS 变量 (最底层) → Tailwind 工具类 (中间层) → 组件样式 (应用层)
```

**动态 CSS 变量生成：**
- 主题色自动生成 50-900 色阶
- 支持透明度调节 `rgb(var(--primary-color) / 50%)`
- 亮/暗模式变量自动切换

### 新增：Naive UI 主题配置

实现 Naive UI 组件库的主题系统集成，包括暗色模式适配和主题色覆盖。

#### 核心实现

**NConfigProvider 全局配置：**
```
App.vue (根组件)
    └── NConfigProvider (Naive UI 全局配置)
            ├── :theme="naiveDarkTheme"           ← 暗色主题对象
            └── :theme-overrides="naiveTheme"     ← 主题颜色覆盖
```

**主题覆盖配置：**
| 组件 | 覆盖内容 |
|------|----------|
| common | 颜色色阶（Hover/Pressed/Active）、圆角 |
| LoadingBar | 加载条颜色 |
| Tag | 标签圆角 |
| Button | 主色文字颜色（白色） |
| Card | 卡片圆角 |
| Modal/Drawer | 弹窗圆角 |
| Input/Select | 输入框圆角 |

#### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `frontend/src/App.vue` | 配置 NConfigProvider，绑定 theme 和 theme-overrides |
| `frontend/src/types/naive-ui.d.ts` | 新增 NaiveUI 命名空间类型定义：ThemeColor, Align, TableColumn |
| `frontend/src/store/modules/theme/index.ts` | 添加 `naiveTheme` 计算属性 |
| `frontend/src/store/modules/theme/shared.ts` | 添加 `getNaiveTheme()` 函数，生成 GlobalThemeOverrides 配置 |

#### 使用方式

```vue
<!-- 使用 ThemeColor 类型 -->
<n-tag type="success">成功</n-tag>
<n-tag type="error">失败</n-tag>
<n-tag type="primary">主要</n-tag>

<!-- 暗色模式自动适配 -->
<n-config-provider :theme="darkMode ? darkTheme : undefined">
```

#### 修复记录

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 主题切换页面无变化 | CSS 变量值为完整 `rgb()` 字符串，导致使用时出现 `rgb(rgb(...))` 无效 CSS | 修改 `settings.ts` 中的 token 颜色值为纯 RGB 分量格式，如 `255 255 255` |
| 初始化时无主题样式 | Pinia Store 的 watch 在组件使用前不会触发 | 添加 `init()` 方法，在 main.ts 应用启动时手动调用初始化 |

## 迁移说明

### 主要 API 差异

| Element Plus | Naive UI |
|-------------|----------|
| `ElMessage.xxx()` | `useMessage()`（setup 内调用） |
| `ElMessageBox.confirm()` | `useDialog()` + `dialog.xxx()` |
| `<el-table-column>` 标签 | `columns` 数组配置 |
| `<el-menu>` 插槽 | `n-menu` 的 `options` 属性 |
| `<el-dropdown>` 插槽 | `n-dropdown` 的 `options` 属性 |

### 验证方式

```bash
# 本地开发
cd frontend && pnpm install && pnpm dev

# 容器部署
./start-local.ps1  # Windows
./start-local.sh   # Linux/Mac
```
