## 前端

### UI 框架迁移：Element Plus → Naive UI

| 文件 | 修改内容 |

| `frontend/src/views/users/UserList.vue` | `el-table` → `n-data-table`，`el-pagination` → `n-pagination`，`ElMessageBox` → `useDialog()` |
| `frontend/src/views/menus/MenuList.vue` | `el-tree-select` → `n-tree-select`，`el-radio-group` → `n-radio-group`，`el-switch` → `n-switch` |
| `frontend/src/api/request.ts` | 移除 `element-plus` 导入，错误处理改为返回 `Promise.reject({message})` |

## 迁移说明

### 主要 API 差异

| Element Plus | Naive UI |
|-------------|----------|
| `ElMessage.xxx()` | `useMessage()`（setup 内调用） |
| `ElMessageBox.confirm()` | `useDialog()` + `dialog.xxx()` |
| `<el-table-column>` 标签 | `columns` 数组配置 |
| `<el-menu>` 插槽 | `n-menu` 的 `options` 属性 |
| `<el-dropdown>` 插槽 | `n-dropdown` 的 `options` 属性 |

### 验证方式

```bash
# 本地开发
cd frontend && pnpm install && pnpm dev

# 容器部署
./start-local.ps1  # Windows
./start-local.sh   # Linux/Mac
```
