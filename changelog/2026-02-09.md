# 2026-02-09 更新日志

## 规范与规则

### 新增：API 接口命名规范

创建项目级 API 设计规范文档，统一 RESTful 接口命名标准。

**核心原则：**
- 资源使用复数形式：`/users`, `/roles`, `/menus`
- 子资源层级关系：`/users/:id/roles`
- 查询参数用于过滤/格式：`/menus?format=flat`

**文档位置：**
- `.claude/rules/api-design.md` - API 命名规范规则

## 后端

### 优化：接口规范化重构

根据 API 设计规范，重构 Controller 层接口，统一为 RESTful 风格。

#### UsersController

| 变更 | 路径 | 说明 |
|------|------|------|
| 新增 | `GET /users/me` | 获取当前用户（替代 `/users/profile`）|
| 新增 | `PATCH /users/:id` | 更新用户信息 |
| 新增 | `DELETE /users/:id` | 删除用户 |
| 新增 | `GET /users/:id/menus` | 子资源：获取用户菜单 |
| 保留 | `GET /users/profile` | 向后兼容 |

#### MenusController

| 变更 | 原路径 | 新路径 | 说明 |
|------|--------|--------|------|
| 修改 | `GET /menus/flat` | `GET /menus?format=flat` | 改为查询参数 |
| 移除 | `GET /menus/role/:roleId` | `GET /roles/:id/menus` | 迁移至 RolesController |
| 移除 | `GET /menus/user/:userId` | `GET /users/:id/menus` | 迁移至 UsersController |

#### RolesController

| 变更 | 路径 | 说明 |
|------|------|------|
| 新增 | `GET /roles/:id/menus` | 子资源：获取角色菜单 |
| 新增 | `PATCH /roles/:id/menus` | 子资源：分配菜单 |

#### 修改文件

| 文件 | 修改内容 |
|------|----------|
| `backend/src/users/users.controller.ts` | 新增 me, update, remove, getUserMenus 接口 |
| `backend/src/users/users.service.ts` | 新增 update, remove, getUserMenus 方法 |
| `backend/src/users/dto/update-user.dto.ts` | **新增** - 用户更新 DTO |
| `backend/src/menus/menus.controller.ts` | 移除角色/用户菜单接口，修改扁平列表为查询参数 |
| `backend/src/roles/roles.controller.ts` | 新增 getRoleMenus, assignMenus 接口 |
| `backend/src/roles/roles.service.ts` | 新增 getRoleMenus, assignMenus, buildTree 方法 |
