# 2026-02-13 更改记录

## 后端 (Backend)

### 核心规范
- **API 规范**: 新增 `.claude/rules/api-design.md`，统一 RESTful API 响应格式、路由命名及 DTO 验证标准。

### 用户管理 (Users)
- **DTO 更新**: `UpdateUserDto` 新增 `email` 和 `password` 可选字段。
- **Controller/Service**: 按照新 API 规范重构用户接口，优化返回数据结构。

### 角色管理 (Roles)
- **接口扩展**:
  - 实现角色更新 (`updateRole`) 和删除 (`deleteRole`) 功能。
  - 实现角色权限（菜单）查询 (`getRoleMenus`) 和分配 (`assignRoleMenus`) 接口。

### 菜单管理 (Menus)
- **规范重构**: 优化菜单控制器，确保符合统一的 API 规范。

---

## 前端 (Frontend)

### API 层 (API Layer)
- **用户接口 (`api/user.ts`)**:
  - 新增 `getCurrentUser`, `updateUser`, `deleteUser` 接口。
  - 新增 `getUserMenus` 接口，用于获取指定用户的菜单权限。
- **角色接口 (`api/roles.ts`)**:
  - 新增/完善角色 CRUD 接口及菜单权限分配接口。
- **菜单接口 (`api/menu.ts`)**:
  - 规范化菜单查询接口。

### 状态管理 (Stores)
- **Auth Store**: 重构认证逻辑，从 `api/user.ts` 调用用户信息和权限，减少模块间交叉引用。

### 全局配置 & UI
- **主题设置**: 默认主题由 `light` 切换为 `dark`。
- **类型定义**: 同步后端 DTO 变化，更新前端 `UpdateUserDto` 类型。
- **布局优化**: 简化侧边栏菜单组件，移除冗余的主题属性绑定。
