# 2026-02-25 更改记录

## 概述
本次提交完成 V1.0 版本的销售管理模块和库存管理增强功能，实现完整的进销存业务闭环。新增销售订单、销售退货、发货管理、库存调整、库存调拨、库存日志查询以及购物车功能。

---

## 后端 (Backend)

### 📦 进销存 - 销售管理

#### 销售订单 (Orders)
- **新增模块**:
  - `orders.module.ts`, `orders.controller.ts`, `orders.service.ts`
  - DTOs: `create-order.dto.ts`, `update-order.dto.ts`, `query-order.dto.ts`, `confirm-order.dto.ts`
  - VO: `order.vo.ts`

- **数据库表**: `Order`, `OrderItem`
  - 支持订单类型区分（SALE-销售单/MALL-商城订单）
  - 订单状态流转：PENDING → CONFIRMED → SHIPPING → SHIPPED → COMPLETED / CANCELLED
  - 支付状态：UNPAID → PARTIAL → PAID
  - 发货状态：UNSHIPPED → PARTIAL → SHIPPED

#### 销售退货 (Sale Returns)
- **新增模块**:
  - `sale-returns.module.ts`, `sale-returns.controller.ts`, `sale-returns.service.ts`
  - DTOs: `create-sale-return.dto.ts`, `update-sale-return.dto.ts`, `query-sale-return.dto.ts`, `audit-sale-return.dto.ts`
  - VO: `sale-return.vo.ts`

- **数据库表**: `SaleReturn`, `SaleReturnItem`
  - 支持基于订单退货和直接退货两种模式
  - 退货状态：PENDING → APPROVED → COMPLETED / REJECTED
  - 审核后自动恢复库存

#### 发货管理 (Shipments)
- **新增模块**:
  - `shipments.module.ts`, `shipments.controller.ts`, `shipments.service.ts`
  - DTOs: `create-shipment.dto.ts`, `update-shipment.dto.ts`, `query-shipment.dto.ts`, `ship-goods.dto.ts`, `receive-goods.dto.ts`
  - VO: `shipment.vo.ts`

- **数据库表**: `Shipment`, `ShipmentItem`
  - 支持分批发货、物流跟踪
  - 发货状态：PENDING → SHIPPED → RECEIVED
  - 发货时自动锁定库存，确认收货后扣减实际库存

### 📦 库存管理增强 (Inventory Management)

#### 库存调整 (Adjustments)
- **新增模块**:
  - `adjustments.module.ts`, `adjustments.controller.ts`, `adjustments.service.ts`
  - DTOs: `create-adjustment.dto.ts`, `query-adjustment.dto.ts`, `audit-adjustment.dto.ts`
  - VO: `adjustment.vo.ts`

- **数据库表**: `Adjustment`, `AdjustmentItem`
  - 支持库存盘盈、盘亏调整
  - 调整类型：PROFIT（盘盈）/ LOSS（盘亏）
  - 状态流转：PENDING → APPROVED / REJECTED
  - 审核后自动更新库存数量

#### 库存调拨 (Transfers)
- **新增模块**:
  - `transfers.module.ts`, `transfers.controller.ts`, `transfers.service.ts`
  - DTOs: `create-transfer.dto.ts`, `query-transfer.dto.ts`, `audit-transfer.dto.ts`, `ship-transfer.dto.ts`, `receive-transfer.dto.ts`
  - VO: `transfer.vo.ts`

- **数据库表**: `Transfer`, `TransferItem`
  - 支持多仓库间库存调拨
  - 状态流转：PENDING → APPROVED → SHIPPED → RECEIVED / REJECTED
  - 出库时锁定库存，入库时释放并扣减

#### 库存日志 (Inventory Logs)
- **新增功能**:
  - `inventories.controller.ts`: 新增 `GET /inventories/:id/logs` 接口
  - DTO: `query-inventory-log.dto.ts`
  - VO: `inventory-log.vo.ts`

- **数据库表**: `InventoryLog`
  - 记录所有库存变动（入库、出库、调拨、调整、销售等）
  - 支持正向/逆向流水查询
  - 字段：变动前数量、变动数量、变动后数量、业务类型、关联单号

#### 库存服务优化
- `inventories.service.ts`:
  - 新增库存变动日志记录方法
  - 优化库存计算逻辑
  - 支持库存预警查询增强

### 🛒 商城模块 - 购物车 (Carts)
- **新增模块**:
  - `carts.module.ts`, `carts.controller.ts`, `carts.service.ts`
  - DTOs: `add-to-cart.dto.ts`, `update-cart.dto.ts`, `query-cart.dto.ts`
  - VO: `cart.vo.ts`

- **数据库表**: `Cart`
  - 支持游客购物车（未登录）和会员购物车
